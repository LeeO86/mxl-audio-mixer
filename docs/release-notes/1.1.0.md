# mxl-audio-mixer 1.1.0 — release notes

Milestone 7 (voice detection, auto-level, auto-mix, ducking). The maintainers'
checks are `docs/release-notes/1.1.0-checklist.md`. This file is filled as those
land. One change is already decided, and it breaks a default.

## Breaking default: ports

| Setting | 1.0.0 | 1.1.0 |
| --- | --- | --- |
| `WEB_PORT` | 8160 | **8190** |
| `NMOS_PORT` | 3312 | **3342** |
| NMOS events WebSocket | 3313 | **3343** |

8160 and 3312 are another media function's ports on the same nodes. A deployment
that relied on the 1.0.0 defaults without setting `WEB_PORT` and `NMOS_PORT`
moves to 8190 and 3342. Set the old values to keep them. The image `EXPOSE`,
`deploy/k8s/deployment.yaml`, `scripts/demo.sh` and the AMWA test's default
ports follow.
